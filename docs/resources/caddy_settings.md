# opnsense_caddy_settings (Resource)

Manages Caddy global settings. This singleton must be imported with `caddy_settings` before use. Destroy removes it from Terraform state without changing OPNsense.

## Example Usage

```terraform
import {
  to = opnsense_caddy_settings.main
  id = "caddy_settings"
}

resource "opnsense_caddy_settings" "main" {
  enabled       = true
  http_port     = 8080
  https_port    = 8443
  listen_addresses = ["192.0.2.10", "10.0.0.2"]
  acme_email    = "operations@example.com"
  run_as_user   = "www"
  http_versions = ["h1", "h2"]
}
```

## Schema

### Required

- `listen_addresses` (Set of String) Explicit IPv4 and IPv6 addresses on which all Caddy HTTP and HTTPS frontends listen. A non-empty set is required to prevent wildcard listeners.

### Optional

- `acme_email` (String) Email address used by public ACME issuers such as Let's Encrypt and ZeroSSL. Defaults to `""`.
- `auto_https` (String) Global automatic HTTPS mode: empty for enabled, `off`, `disable_redirects`, `disable_certs`, or `ignore_loaded_certs`. Defaults to enabled.
- `enable_layer4` (Boolean) Whether to enable Layer 4 routing. Defaults to `false`.
- `enabled` (Boolean) Whether to enable Caddy. Defaults to `false`.
- `grace_period` (Number) Grace period in seconds for closing connections during reload. Defaults to `10`.
- `http_port` (Number) Local HTTP listen port. Defaults to `80`.
- `http_versions` (Set of String) Frontend HTTP versions: `h1`, `h2`, and optionally `h3`. Defaults to `h1` and `h2`.
- `https_port` (Number) Local HTTPS listen port. Defaults to `443`.
- `log_level` (String) Global log level. Empty means INFO; alternatives are DEBUG, WARN, ERROR, PANIC, or FATAL. Defaults to INFO.
- `plain_access_log` (Boolean) Whether to write HTTP access logs to plain JSON files. Defaults to `false`.
- `plain_access_log_keep` (Number) Number of rotated plain access logs to retain. Defaults to `10`.
- `run_as_user` (String) Operating-system account used to run Caddy: `root` or `www`. Defaults to `root`.

### Read-Only

- `id` (String) Always `caddy_settings`.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) to import opnsense_caddy_settings using the fixed ID `caddy_settings`.

```terraform
import {
  to = opnsense_caddy_settings.example
  id = "caddy_settings"
}
```

Using `terraform import`:

```console
% terraform import opnsense_caddy_settings.example caddy_settings
```
